# 文章页：词云与文章列表

## 页面行为

- `/articles` 首屏保留旋转词云，桌面和手机都能点击标题进入原有详情页。
- 向下滚动或点击“向下浏览文章”，进入传统文章列表。
- 搜索覆盖公开索引已有的标题、文件名、摘要、标签及文档格式，大小写和全角英文兼容，多个关键词同时匹配；不额外请求所有正文，不宣称全文检索。
- 支持文档格式筛选，每页八项，切换搜索或格式后回到第一页；空结果可一键重置。
- 正常加载、真实空列表、接口失败和格式异常分别展示，失败有重试入口。无效的 1970 年文件时间不显示。
- 保留固定导航、透明玻璃、现有配色和文章详情。词云滚离可视区或标签隐藏时停止重画，返回可视区恢复；减少动态效果偏好下保持静态。

## 实现入口

- `src/views/Articles.vue`：布局、搜索、筛选、分页和可视区管理。
- `src/utils/articleIndex.js`：共用索引整理、搜索与详情路径编码。
- `src/components/TagCloudCanvas.vue`：复用既有命中逻辑，增加可暂停绘制能力。
- `tests/articleIndex.test.mjs`：搜索与索引边界测试，运行 `node --test tests/articleIndex.test.mjs`。

接口沿用 `GET /api/article-index`，没有新增 API、改变数据库结构、读取草稿或写正式内容。数据库文章索引不含完整正文，因此搜索范围以接口返回的公开元数据为准。
